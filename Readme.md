# ✨ AI Meeting Assistant

An AI-powered meeting assistant that converts unstructured meeting input into structured insights like summary, key points, and action items.

## 🚀 Features

- 🎙️ Voice input using Web Speech API  
- 🧠 AI processing using Ollama (local LLM)  
- 📊 Structured output (Summary, Key Points, Action Items)  
- ⌨️ Typing animation for responses  
- 🤖 AI thinking loader  
- 🎨 Modern animated UI  

## 🛠️ Tech Stack

- Frontend: React (Vite)
- Backend: Node.js + Express
- AI: Ollama (local LLM)
- Speech Recognition: Web Speech API

## ⚙️ How to Run

1. Clone the repository
2. Install dependencies in both client and server
3. Start backend server
4. Start frontend
5. Make sure Ollama is running locally

## 🔮 Future Scope

- Real-time meeting integration (Zoom/Google Meet)
- Save meeting history
- Export summaries as PDF
